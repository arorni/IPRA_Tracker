====================================================
PROBLEM OVERVIEW
====================================================

Build a system that helps users:

1. Create public records requests
2. Improve request wording using AI
3. Prepare requests for submission
4. Track statutory deadlines
5. Store returned records
6. Summarize uploaded records
7. Suggest follow-up requests

====================================================
CORE WORKFLOW
====================================================

1. User creates request
2. AI improves request draft
3. App stores request
4. User reviews request
5. User submits request outside the app using the agency's preferred method:
   - email
   - portal
   - mail
   - other

6. User returns to app
7. User marks request as submitted
8. App calculates deadlines
9. App displays reminder information
10. User uploads returned records
11. AI summarizes records
12. AI suggests follow-up requests

====================================================
IMPORTANT IPRA RULES
====================================================

Implement ONLY these rules:

- Records should be made available immediately or as soon as practicable.

- Records should be made available no later than 15 calendar days after receipt.

- If records are not available within 3 business days, the agency should provide a written response explaining when records will be available or when it will respond.

Do NOT hallucinate or invent legal rules beyond these.

- Mail
- Phone
- Other

Default:

"Submitted through agency portal"

Buttons:

[Cancel]

[Confirm Submission]

On confirmation:

Update database:

status = submitted

submitted_date

submission_method

submission_notes

Then automatically:

- calculate 3-business-day deadline
- calculate 15-calendar-day deadline
- update dashboard
- update status indicators

Show message:

"Request marked as submitted. Deadline tracking has started."
