Important status rules:

1. Draft
Use when the request is still incomplete or not finalized.

2. Ready to Submit
Use only after the user has reviewed/finalized the request.
This does NOT mean the request has been submitted to the agency.
Do NOT calculate deadlines at this stage.

3. Submitted
Use only after the user clicks Mark as Submitted and confirms:
- submission method
- submission date
- optional notes

Only after this confirmation should deadline tracking begin.

4. Records Received
Use when the user confirms that the agency returned records/documents.

5. Closed
Use when the user is done with the request.

6. Overdue
Do NOT make Overdue a manual status.
Overdue should be calculated automatically based on deadlines.

Remove “Awaiting Response” as a separate manual status.
If needed, show “Awaiting agency response” as a sub-label under Submitted.
