I want to build a professional MVP web app for managing New Mexico IPRA public records requests.

Problem overview:
The app helps users create, draft, submit/prepare, track, store, summarize, and follow up on New Mexico Inspection of Public Records Act (IPRA) requests.

Core workflow for v1:
1. User creates a public records request.
2. AI helps improve the request draft.
3. App stores the request.
4. User manually submits the request outside the app or by email.
5. User marks the request as submitted.
6. App calculates and tracks:
   - 3 business day response deadline
   - 15 calendar day production deadline
7. App shows deadline status and reminders.
8. User uploads returned records/documents.
9. AI summarizes uploaded records.
10. AI suggests possible follow-up requests.

Important IPRA timing rules to encode:
- Records should be made available immediately or as soon as practicable.
- Records should be made available no later than 15 calendar days after receipt.
- If records are not available within 3 business days, the agency should provide a written response explaining when records will be available or when it will respond.
